# Library Management System

A backend application built using Java and Spring Boot to manage library operations through REST APIs.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- JWT Authentication
- Maven

## Features
- Book CRUD operations
- Book issue and return management
- Fine calculation
- Pagination, sorting, and searching
- User authentication and authorization
- RESTful APIs
- Exception handling

## Prerequisites
- Java
- MySQL
- Maven

## Setup
1. Clone this repository.
2. Create a MySQL database named `library_db`.
3. Configure your local database credentials and JWT secret in `application.properties`.
4. Run the application from your IDE or using Maven.
